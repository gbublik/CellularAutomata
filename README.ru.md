# Cellular Automata — лаборатория трёхмерных клеточных автоматов на Unreal Engine 5.7

[English](README.md) | **Русский**

Песочница для исследования трёхмерных клеточных автоматов в реальном времени: посей паттерн, выбери правило — и смотри, как структуры растут, ползут, стареют и рушатся, при **~7 миллионах живых клеток в реальном времени**. Всё построено вокруг *разглядывания* того, что выросло: ортографические камеры в духе DCC-пакетов, срезы, раскраска по возрасту, PNG-захват прямо из сетки, сонификация — периодичность и коллапс слышно раньше, чем видно, — и свой формат сохранений для коллекции находок.

## Возможности

- **Симуляция** — чанковая битовая сетка (разреженная, с центром в начале координат — отрицательные координаты здесь норма); CPU- и GPU-стратегии (compute shader); шаг считается вне игрового потока; несколько поколений на один кадр рендера (`StepsPerRender`); шаг назад через детерминированный пересчёт (Ctrl+Z).
- **Правила** — строки вида `Survival/Birth/States/Neighborhood`, библиотека пресетов, многосостоянийный распад в духе Generations («летающие стержни» и прочее). **15 соседств** из четырёх оболочек радиуса 2 плюс одно анизотропное планарное.
- **Решётки** — клетка не обязана быть кубом: пять заполняющих пространство многогранников (полная классификация Фёдорова, 1885 — куб, ромбододекаэдр, усечённый октаэдр, удлинённый додекаэдр; шестигранная призма в планах), у каждого свой меш и своё преобразование решётки. Фильтры чётности дают ГЦК/ОЦК-решётки бесплатно.
- **Рендер** — один инстансированный компонент, поинстансная раскраска по возрасту/распаду, четыре профиля рендера на F1–F4, дистанционный куллинг, подвижный объём отсечения, срезы обзора и режим «только поверхность»: тело из 14 млн клеток рисуется как ~350 тыс. инстансов с попиксельно той же картинкой. Чанковый (размазанный по кадрам) ребилд для огромных сеток.
- **Редактирование** — выделение рамкой и лучом (воксельный DDA), режим рисования с призраком под курсором, буфер обмена с поворотами на 90°, Array-модификатор в духе Blender и журнал правок, переживающий сброс: ручные правки переигрываются поверх пересчитанной траектории.
- **Генераторы** — решётки, тела, шум, симметричные сиды; гистограмма числа соседей для подбора правила под структуру; автоперепосев (Shift+N), который перебрасывает сид при вымирании/стазисе/взрыве и позволяет охоте идти без присмотра.
- **Сонификация** — кривая популяции (в лог-пространстве) управляет MetaSound-графом: наклон, кривизна, триггеры событий; осцилляторы и вымирания слышно раньше, чем видно.
- **Захват** — ортогональные PNG-срезы прямо из сетки (без GPU, без предела разрешения; F6/F7 — один/серия), фоторежим F10 и сферическая панорама Shift+F10 (шесть кадров, сшитых в одну равнопромежуточную PNG).
- **Сохранения** — контейнер `.casave`: правило, *начальный* паттерн и миниатюра. Alt+S всегда пишет новый автоименованный файл — коллекция находок не может затереть сама себя.

## Требования

- **Windows 10/11** (проект разрабатывается и проверяется на Windows; для Linux известных блокеров нет, но это не проверено)
- **Unreal Engine 5.7** из Epic Games Launcher
- **Visual Studio 2022** с воркнагрузкой *Game development with C++* — в репозитории лежит `.vsconfig`, так что VS сам предложит доустановить недостающее
- ~2 ГБ на диске под клон плюс обычный кеш DerivedDataCache

## Быстрый старт

```
git clone <этот репозиторий>
```

1. Правый клик по `CellularAutomata.uproject` → **Generate Visual Studio project files** (или командой ниже).
2. Открой `CellularAutomata.sln`, выбери **Development Editor | Win64**, собери и запусти — либо просто дважды кликни `.uproject` и согласись на компиляцию.
3. Редактор откроет уровень по умолчанию. Нажми **Play** (PIE) — начальный паттерн сгенерируется сам.
4. Нажми **Пробел** — симуляция пошла.

Те же шаги из командной строки:

```powershell
# Сгенерировать файлы проекта
& "C:\Program Files\Epic Games\UE_5.7\Engine\Build\BatchFiles\Build.bat" -projectfiles -project="<repo>\CellularAutomata.uproject" -game -rocket -progress

# Собрать редакторский таргет
& "C:\Program Files\Epic Games\UE_5.7\Engine\Build\BatchFiles\Build.bat" CellularAutomataEditor Win64 Development -Project="<repo>\CellularAutomata.uproject"
```

## Управление (главное)

Все горячие клавиши лежат в `Config/DefaultInput.ini` (строки `CA_*`) и перепривязываются прямо там; полный аннотированный список — в [docs/input-and-camera.md](docs/input-and-camera.md).

| Клавиша | Действие |
|---|---|
| **Пробел** | запустить / поставить симуляцию на паузу |
| **N** | новый случайный сид (Shift+N — автоперепосев-поиск) |
| **R** | сброс к начальному паттерну |
| **Ctrl+Z** | шаг назад |
| **Y** | перегенерировать текущим генератором (Ctrl+Y — гистограмма соседей) |
| **+/-** | скорость симуляции · **T / G** — поколений на кадр рендера |
| **F1–F4** | профили рендера · **F5** — инфопанель HUD |
| **1–0** | фильтры возраста |
| **Tab** | режим выделения · **Shift+Tab** — режим рисования (ЛКМ ставит, ПКМ стирает) |
| **Enter** | оставить только выделение · **Delete** — удалить выделенные клетки |
| **Ctrl+C / Ctrl+V** | копировать / вставить клетки (стрелки крутят буфер на 90°) |
| **Ctrl+D** | Array-модификатор |
| **F6 / F7** | PNG-срез / серия срезов · **F10** — фото · **Shift+F10** — панорама 360° |
| **Ctrl+S / Ctrl+O** | сохранить / загрузить `.casave` · **Alt+S** — быстрое сохранение находки |
| **P** | сонификация вкл/выкл |
| **NumPad 1–9** | осевые / изометрический виды · **NumPad 5** — ортопроекция · **Home** — показать всё |

## Тесты

Набор из 27 автотестов покрывает логику, не требующую актора (математика сетки, парсер правил, выделение, цветовые рампы — см. [docs/testing.md](docs/testing.md)):

```powershell
& "C:\Program Files\Epic Games\UE_5.7\Engine\Binaries\Win64\UnrealEditor-Cmd.exe" "<repo>\CellularAutomata.uproject" -ExecCmds="Automation RunTests CellularAutomata" -testexit="Automation Test Queue Empty" -unattended -nopause -nosplash -abslog=<файл_лога>
```

## Опционально: автоматизация редактора через MCP

`Plugins/McpAutomationBridge` (сторонний, MIT) открывает работающий редактор по HTTP для AI-инструментов — спавн акторов, скриншоты, консольные команды. В рантайме полностью опционален; см. [docs/tooling.md](docs/tooling.md).
